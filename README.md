# random_programs
Just a bunch of random programs I made.

## Contents

- `rs_alchemy/` — scraper for RuneScape 3 Grand Exchange price and high-alchemy data (prices.runescape.wiki), into pandas DataFrames and HDF5.
- `cgui/` — cross-platform custom-drawn GUI toolkit in C (transparent/rounded frames, window buttons along the top-right curve), plus **preetum**, a menu of small tools built on it (Font Compare, Glyph Map).
