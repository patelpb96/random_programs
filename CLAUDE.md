# random_programs

A collection of unrelated projects, each in its own directory with its own README.

| Directory | What | Start here |
|---|---|---|
| `cgui/` | C99 custom-drawn GUI toolkit plus **preetum**, a menu of small tools built on it. This is the active project. | **Read `cgui/CLAUDE.md` before doing anything in `cgui/`.** It links the architecture, design rationale, pitfalls, extension guide and roadmap in `cgui/docs/`. |
| `rs_alchemy/` | Python scraper for RuneScape 3 Grand Exchange and high-alchemy data. | `rs_alchemy/README.md` |

The owner sometimes pushes commits directly, so run `git pull` before starting work.
